\section{Introduction}
\label{sec:intro}
Resistive RAM (RRAM) stores data as the conductance of a two-terminal device, and in a one-transistor-one-resistor (1T1R) array this conductance can be read in parallel.
When several word lines open at once, the bit line sums the conductances of the selected cells, and the array becomes a computing element rather than a store.
A multi-row read then yields bulk bitwise operations~\cite{li2016pinatubo} or an analog multiply-accumulate (MAC)~\cite{chi2016prime,shafiee2016isaac} in a single access~\cite{ielmini2018inmemory}, and stateful memristive logic complements it by writing the result back into a cell as a material implication~\cite{borghetti2010memristive}, a NOR~\cite{kvatinsky2014magic}, or a majority~\cite{gaillardon2016plim}.
Silicon demonstrations of this processing-in-memory (PiM) have relied on dedicated sense circuits with tracking references or calibration~\cite{chen2018rram65nm,wan2022neurram}, and time-domain readouts with time-to-digital converters (TDCs) have digitized in-memory MAC compactly~\cite{sayal2020timedomain,xue2024tdcim}.
For RRAM, time-domain readout has been proposed for 1T1R MAC~\cite{sahay2020vmm} and demonstrated in a 22\,nm 8-Mb macro~\cite{hung2023rram}, and a FeFET macro derives in-memory AND and OR from fixed taps of its thermometer code after per-cell delay calibration~\cite{mattar2025fefet}.

Every one of these read circuits is designed against a device model, and this is where RRAM departs from a mature memory.
The compact model of an RRAM module is fitted to a few programmed states, and it captures neither the resistance spread of a verify-programmed array nor the capacitance of the memory stack itself, while the fabricated arrays differ from the model, and from one another, in both.
On the HfAlO module used here, the high-resistance state lands anywhere between 60 and 220\,k$\Omega$ depending on the reset verify, and its spread across devices is 0.5 to 1 in $\ln R$~\cite{perez2017hfalo,baroni2025aldoping}.
A reference-tracked sense amplifier compares against reference cells programmed with the same uncertain device, and a calibration loop still has to be designed before the devices are characterized.
What remains open is a read whose decision point does not come from the model at all, but is placed after the fabricated cells have been measured.

This work proposes a time-domain read with exactly that property.
Instead of a voltage-mode sense amplifier, every column converts the time the bit line takes to discharge through the selected cells into a thermometer code with an eight-tap delay-line TDC, and the sampling window, the tap pitch, and the drive levels are set by registers and supply pads rather than by transistor sizing.
Because the decision is a threshold on a code, opening several rows turns the same read into an in-memory NOR or majority.
The read path and its controller are implemented in a tape-out-ready 64$\times$64 1T1R macro.
Post-layout simulation with the extracted bit-line loading separates a single row by all eight taps and resolves an 8-row NOR by six taps and an 8-row majority by two, and an access returns 64 decisions in 0.45\,\si{\micro\second} for 64 to 107\,pJ.
A Monte Carlo analysis on these margins then turns the evaluation into a budget for the device, namely the resistance spread each operation tolerates, which the single-row read meets at the edge of the characterized high-resistance state and the multi-row logic meets with a deeper reset.
