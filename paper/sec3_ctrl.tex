\section{Controller and Read Sequencing}
\label{sec:ctrl}
Each macro is driven by a 21-state FSM with 12 operations (Fig.~\ref{fig:macro}): single and
complete reads, SET, RESET and mixed-polarity writes of a 64-bit word into the selected rows,
precharge, a discharge-length test (READ pulsed with the drain on until the column code reaches
zero, measuring slow or pristine cells) and a sample capture (READ\_SAMPLE: a READ pulse every 20\,ns, sixteen codes). A read precharges for
a programmable number of cycles, opens the row mask for a settle time, and applies
DRAIN$_\mathrm{SL}$ and READ with a \emph{signed} offset: a positive offset turns the drain on
first, so the TDC samples later in the discharge.  Eight 32-bit
registers (control, row mask, data word, timings, status, paged result) are written from a host
over a serial link, and a host procedure searches $\Vg$, $\Vdel$, $\Vd$, settle and offset for
the operating point that best separates the classes of each operation, the procedure used in
Section~\ref{sec:results}.
