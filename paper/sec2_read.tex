\section{Post-Fabrication-Tunable Time-Domain Read}
\label{sec:read}
\begin{figure}[!t]
\centering
\includegraphics[width=\columnwidth]{schematic}
\caption{(a) One column of the macro with its TDC. (b) Read sequence: the source line is grounded as the rows open, and the eight-tap window (shaded) samples the discharge after the offset.}
\label{fig:schematic}
\end{figure}
A conventional sense amplifier asks whether the bit line is above or below a reference at one instant, whereas the read of Fig.~\ref{fig:schematic} asks how long the bit line takes to discharge.
A read precharges the bit line BL to the drive voltage $\Vd$, grounds the source line SL and opens the selected rows, so that BL discharges through the selected cells with a time constant set by the cell resistance, the access-transistor resistance, and the bit-line capacitance.
A buffer with a threshold of about 0.6\,V converts BL into a digital signal, and eight flip-flops sample this signal on the eight taps of a delay line that a READ pulse triggers.
The result is a thermometer code that counts the taps at which BL was still high, so that a low-resistance (LRS) cell gives a short code and a high-resistance (HRS) cell a long one (Fig.~\ref{fig:schematic}(b)).

Three knobs place the decision, and none of them is a transistor size.
The controller inserts a signed offset between its drain step and the READ pulse in 10\,ns steps, positive when the drain comes first, so READ follows the drain step by one cycle plus the offset; a dedicated supply pad $\Vdel$ sets the delay of the line and with it the tap pitch; and the word-line supply $\Vg$ sets the access-transistor resistance together with the level-shifter delay.
The first tap fires 3.4\,ns after the READ edge, and the pitch is 0.35, 0.24, and 0.18\,ns at $\Vdel=0.8$, 0.9, and 1.0\,V, so the window spans 2.5 to 1.3\,ns; below about 0.7\,V the swing of the line no longer clocks the 1.2\,V sampling flip-flops, which bounds the window to about 5\,ns, narrower than the step in which it moves.
All three are registers or pads, so the window is placed after the fabricated cells have been measured, with no reference cell programmed from the same uncertain device.

With $n$ rows open, the column conductance is the sum of the selected cells, so the discharge time, and with it the code $c(k)$, falls monotonically with the number $k$ of LRS cells among them.
A NOR over the $n$ rows separates $k=0$ from $k\ge1$ with a margin of $c(0)-c(1)$, and a majority separates $k\le n/2$ from $k>n/2$ with a margin of $c(n/2)-c(n/2+1)$.
