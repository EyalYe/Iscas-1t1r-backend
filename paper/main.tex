\title{A Post-Fabrication-Tunable Time-Domain Multi-Row Read for RRAM Processing-in-Memory}

\author{\IEEEauthorblockN{Eyal Yemini, Adam Teman, and Leonid Yavits}
\IEEEauthorblockA{Faculty of Engineering, Bar-Ilan University, Ramat Gan, Israel\\
eyal.yemini@live.biu.ac.il}}

\maketitle

\begin{abstract}
Resistive RAM (RRAM) turns a memory array into a computing element, because a read that opens several rows sums the conductances of the selected cells on the bit line.
The circuit that resolves this sum is designed against a device model, yet the compact models of RRAM processes capture neither the resistance spread of a programmed array nor the capacitance of the memory stack, so a read designed for one assumed operating point can miss the point at which the fabricated cells actually sit.
This paper presents a read path whose operating point is chosen after fabrication.
Each column converts the bit-line discharge time into a thermometer code with a delay-line time-to-digital converter, and the sampling window, tap pitch, and drive levels are set from registers and supply pads, so that opening several rows turns a read into an in-memory NOR or majority without a reference cell.
The read path and its controller are implemented in a tape-out-ready 64$\times$64 one-transistor-one-resistor macro.
Post-layout simulation with the extracted bit-line loading separates a single row by all eight taps and resolves an 8-row NOR by six taps and an 8-row majority by two, at 0.13 to 0.2\,pJ per bit, and a Monte Carlo analysis converts these margins into the resistance spread the device has to meet, which the single-row read satisfies at the characterized high-resistance state and the multi-row logic reaches with a deeper reset.
\end{abstract}
